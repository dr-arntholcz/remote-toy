<h1 align="center">Remote Toy</h1>
<h2 align="center">Машинка на управлении через сеть</h2>
<div style="text-align: justify;">Это проект машинки на управлении через сеть. На пк поднимается сервер websocket. Этот сервер написан на Python. Он принимает команды от геймпада и отправляет команды клиенту. Клиентом выступает есп32 с камерой. Так же клиент отправляет на сервер картинку с камеры. Картинка отображается в окне на  сервере.<div>
